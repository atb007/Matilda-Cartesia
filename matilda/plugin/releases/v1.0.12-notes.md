## What's new in v1.0.12

### Jul 2026 standalone freeze, now in VST3/AU source

This release ports the Jul 15 standalone feature freeze into `matilda/plugin/` for the Windows VST3 path while preserving the v1.0.11 silent-instrument / Fruity Wrapper routing fix.

- **Polyphony crown + engine:** optional simultaneous active-layer playback with one active note slot per layer.
- **Rive `faceStreakVis`:** now follows `polyphony && activeLayerCount >= 2 && playing`, so it turns off when only one layer remains active.
- **Per-layer step count:** `active_step_count` is saved in Patch JSON and controlled by the vine `StepScroll`.
- **Layer clipboard:** mini-grid right-click copy/paste/reset/undo; reset leaves cells gate-on at degree 0.
- **Presets:** user preset bar with dirty `*`, seeded `Init`, native Save dialog, and load that preserves current BPM / transport state.
- **Frosted shell glass:** standalone frosted shell treatment is source-ported into the plugin shell.
- **Playhead sync:** mini-grid/main-grid lights use the last fired step (not the post-advance step), including poly playheads.
- **Rive v3 / wordmark:** v3 hero asset and GPU-safe wordmark stack remain enabled for Metal/D3D builds.

### Validation

- Local macOS plugin build passed: `cmake --build matilda/plugin/build --config Release -j8`
- macOS VST3/AU artifacts build locally.
- Windows VST3 / standalone zips are produced by the tag-triggered **Matilda Release** GitHub Actions workflow.

### Install

#### macOS
- **VST3:** unzip `Matilda-macOS-vst3.zip` → copy `Matilda.vst3` to `~/Library/Audio/Plug-Ins/VST3/`
- **Standalone:** unzip `Matilda-macOS-standalone.zip` → open `Matilda.app`

#### Windows (FL Studio, etc.)
- **VST3:** unzip `Matilda-Windows-vst3.zip` → copy `Matilda.vst3` to `C:\Program Files\Common Files\VST3\`
- **Standalone:** unzip `Matilda-Windows-standalone.zip` → run `Matilda.exe`
- Rescan plugins after copying the VST3 folder.
