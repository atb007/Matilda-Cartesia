## What's new in v1.0.15

### Windows — Rive hero (standalone + VST3)

- **New render path:** D3D11 PLS renders **offscreen**, then blits into a `juce::Image` painted by `HeroCanvas`.
- **Why:** the child HWND + DXGI swap-chain path (v1.0.13) still left many installs on the static PNG in standalone and VST hosts.
- **No HWND overlay** for Rive on Windows — wordmark stays a JUCE sibling above the painted frame (same as CG).
- **Device init:** hardware D3D11 with feature-level `11_1` → `11_0`, then **WARP** fallback.
- **Diagnostics:** `%TEMP%\MatildaRiveD3D.log` — look for `first D3D offscreen frame blitted to juce::Image`.

> macOS Rive is unchanged (Metal overlay).

### Install

#### macOS
- **VST3:** unzip `Matilda-macOS-vst3.zip` → copy `Matilda.vst3` to `~/Library/Audio/Plug-Ins/VST3/`
- **Standalone:** unzip `Matilda-macOS-standalone.zip` → open `Matilda.app`

#### Windows (FL Studio, etc.)
- **VST3:** unzip `Matilda-Windows-vst3.zip` → copy `Matilda.vst3` to `C:\Program Files\Common Files\VST3\`
- **Standalone:** unzip `Matilda-Windows-standalone.zip` → run `Matilda.exe`
- Rescan plugins after copying the VST3 folder.

If Rive still fails on Windows, check `%TEMP%\MatildaRiveD3D.log` and attach it when reporting.
