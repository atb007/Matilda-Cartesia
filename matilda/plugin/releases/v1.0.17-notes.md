## What's new in v1.0.17

### Windows — Rive hero framing

- **Right-edge clip fix:** the offscreen D3D path was rendering/painting only the portrait content box, so hair and dress spill were cut on a hard vertical line.
- Match macOS Metal: extend the drawable to the hero mask right edge, keep Cover+CenterLeft aligned to the portrait content box, and blit the wider frame into that overlay rect.

> macOS unchanged.

### Install

#### macOS
- **VST3:** unzip `Matilda-macOS-vst3.zip` → copy `Matilda.vst3` to `~/Library/Audio/Plug-Ins/VST3/`
- **Standalone:** unzip `Matilda-macOS-standalone.zip` → open `Matilda.app`

#### Windows (FL Studio, etc.)
- **VST3:** unzip `Matilda-Windows-vst3.zip` → copy `Matilda.vst3` to `C:\Program Files\Common Files\VST3\`
- **Standalone:** unzip `Matilda-Windows-standalone.zip` → run `Matilda.exe`
- Rescan plugins after copying the VST3 folder.
