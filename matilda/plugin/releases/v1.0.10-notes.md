## What's new in v1.0.10

This release is **Standalone-focused** (especially **macOS**). The **VST3/AU plugin is unchanged** from v1.0.9.

### macOS Standalone: native Rive v2 hero portrait

- **Metal GPU** animated hero (`matilda-cartesia-v2.riv`) with layer-driven data bindings (transport streak, layer-count glows).
- **+10% expanded hero width** in the expanded shell layout.
- **CG CPU fallback** available at build time (`MATILDA_RIVE_BACKEND=cg`); release builds use Metal.
- Rulebook: `matilda/standalone/docs/RIVE_ANIMATION_RULEBOOK.md`.

### Standalone (macOS + Windows): glass dropdown UI polish

- **Fixed-size menu labels** (18px screen-space) — option text no longer scales with UI resize.
- **Auto menu width** — panels expand to fit the widest label (no truncation).
- **Complete rounded frame** — bottom border no longer clipped; removed side-stroke artefacts.
- **Tighter row spacing** — separators only between items (not after the last).
- **Clock menu** — shows **4** visible rows before scrolling (was 6).
- **Scale / Quantise menus** — selected row uses the same **teal highlight** as Global Settings and Movement.

## Install

### macOS
- **Standalone:** unzip `Matilda-macOS-standalone.zip` → open `Matilda.app`
- **VST3:** unchanged from v1.0.9 — unzip `Matilda-macOS-vst3.zip` → copy `Matilda.vst3` to `~/Library/Audio/Plug-Ins/VST3/`

### Windows
- **Standalone:** unzip `Matilda-Windows-standalone.zip` → run `Matilda.exe` (dropdown fixes; no Rive hero — macOS only)
- **VST3:** unchanged from v1.0.9
