## What's new in v1.0.14

### Factory preset library

- **26 Patch v2 factory presets** in `matilda/presets/` plus generator (`generate_factory_presets.py`).
- **Musical:** Trance Classic / Rise, 3rds & 5ths Heaven, Open Sky, Poly 3v4 / 5v8 / 3×4×5, Cloud Drift, Phrygian Knife, Fibonacci Bloom.
- **Abstract / structural:** One Note Universe, Static Field, Binary Clock, Euclid Rain, Signal Fog, Staircase Void, Broken Clock, Prime Swarm, Glass Shatter, Insect Choir, Whale Call, Cathedral Fog, Slow Orbit, Heartbeat, Mirror Lake.

### Preset library path (macOS)

- Library is now explicitly `~/Library/Application Support/IdeasLab/Matilda/presets/` (this JUCE tree’s `userApplicationDataDirectory` is `~/Library`, which previously split saves from the documented folder).
- One-time migration copies older files from `~/Library/IdeasLab/Matilda/presets/`.
- Save always registers the chosen basename into the library so the dropdown stays in sync.

### UI polish

- Mini-knob “Note Trigger” tip sits above the knob so the full label is not clipped by the cell edge.
- Quantise / transport value type size aligned with gem note labels; collapsed shell side gutters balanced.

### Install

#### macOS
- **VST3:** unzip `Matilda-macOS-vst3.zip` → copy `Matilda.vst3` to `~/Library/Audio/Plug-Ins/VST3/`
- **Standalone:** unzip `Matilda-macOS-standalone.zip` → open `Matilda.app`

#### Windows (FL Studio, etc.)
- **VST3:** unzip `Matilda-Windows-vst3.zip` → copy `Matilda.vst3` to `C:\Program Files\Common Files\VST3\`
- **Standalone:** unzip `Matilda-Windows-standalone.zip` → run `Matilda.exe`
- Rescan plugins after copying the VST3 folder.
