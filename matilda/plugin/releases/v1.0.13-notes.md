## What's new in v1.0.13

### Windows — Rive hero (standalone + VST3)

- **D3D swap chain:** use `DXGI_ALPHA_MODE_IGNORE` for HWND swap chains — `PREMULTIPLIED` is rejected by `CreateSwapChainForHwnd`, which prevented the hero from ever presenting a frame (static PNG fallback only).
- **Device init:** D3D11 feature-level fallback `11_1` → `11_0` for older runtimes.
- **Diagnostics:** append failures to `%TEMP%\MatildaRiveD3D.log` (device, import, swap chain, first frame).
- **Fallback:** keep static portrait visible until the first real D3D frame is presented.

### Windows — filigree ornament mirroring

- **Quantise Max** and **Global Settings Play Mode / Clock** right-side ornaments are pre-flipped at load time — paint-time negative-scale transforms silently fail under JUCE 8 Direct2D on Windows.

> macOS builds are unchanged for Rive (Metal). Filigree uses the same shared load-time flip path; visual result matches the prior CoreGraphics paint-time mirror.

### Install

#### macOS
- **VST3:** unzip `Matilda-macOS-vst3.zip` → copy `Matilda.vst3` to `~/Library/Audio/Plug-Ins/VST3/`
- **Standalone:** unzip `Matilda-macOS-standalone.zip` → open `Matilda.app`

#### Windows (FL Studio, etc.)
- **VST3:** unzip `Matilda-Windows-vst3.zip` → copy `Matilda.vst3` to `C:\Program Files\Common Files\VST3\`
- **Standalone:** unzip `Matilda-Windows-standalone.zip` → run `Matilda.exe`
- Rescan plugins after copying the VST3 folder.

If Rive still fails on Windows, check `%TEMP%\MatildaRiveD3D.log` and attach it when reporting.
