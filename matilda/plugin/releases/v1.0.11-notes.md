## What's new in v1.0.11

### FL Studio Fruity Wrapper — channel / mixer / step-sequencer routing fix

On newer FL Studio (e.g. **25.x**), wrapper internal MIDI ports could produce sound but only on the **master** bus — the channel showed no meter activity, step-sequencer lanes stayed empty, and armed MIDI recording captured nothing.

**Cause:** v1.0.5 registered Matilda as a pure **MIDI-FX** (`IS_MIDI_EFFECT`). FL treats MIDI-FX outside the channel-rack instrument path.

**Fix (restores v1.0.3 FL instrument mode):**

- Re-register as a **silent VST3 Instrument** (`IS_SYNTH`, not MIDI-FX).
- **Audio passthrough** when the host supplies input buses.
- Virtual **MIDI Out** streams **note data only** — leave at **(None)** when using wrapper internal ports.

### UI polish — plugin + standalone (forward-ported from v1.0.10)

**Glass dropdown menus** (Movement, Quantise Scale, Transport):

- Fixed **18px screen-space** option labels (no longer shrink with UI resize).
- **Auto menu width** — panels expand to fit the widest label.
- **Complete rounded frame** — no clipped bottom border or side-stroke artefacts.
- Separators **only between items** (not after the last row).
- Clock menu shows **4** visible rows before scrolling (was 6).
- Scale/Quantise selected row uses the same **teal highlight** as Movement.

**Rive v2 hero portrait** (plugin VST3/AU + standalone):

- Native **Metal GPU** (macOS) / **D3D11 GPU** (Windows) animated hero (`matilda-cartesia-v2.riv`).
- Transport play/stop drives `streakVisible`; active layer count drives glow bindings.
- **+10% expanded hero width** in expanded shell layout.
- macOS CG CPU fallback still available at build time (`MATILDA_RIVE_BACKEND=cg`).

**Sync unchanged:** DAW Sync toggle, host transport fallback, opaque-host clock, and virtual MIDI Out fallback all behave as in v1.0.10.

### Fruity Wrapper setup (FL 21+)

1. Channel rack → **Fruity Wrapper** (generator).
2. Slot 1: **Matilda** · Slot 2: your synth.
3. Wrapper: Matilda **MIDI output port N** → synth **MIDI input port N**.
4. Matilda plugin: **MIDI Out → (None)**.
5. Route wrapper channel to a **mixer insert** (not master).

## Install

### macOS
- **VST3:** unzip `Matilda-macOS-vst3.zip` → copy `Matilda.vst3` to `~/Library/Audio/Plug-Ins/VST3/`
- **Standalone:** unzip `Matilda-macOS-standalone.zip` → open `Matilda.app` (**Apple Silicon / arm64** for native Rive hero)

### Windows (FL Studio, etc.)
- **VST3:** unzip `Matilda-Windows-vst3.zip` → copy `Matilda.vst3` to `C:\Program Files\Common Files\VST3\`
- **Standalone:** unzip `Matilda-Windows-standalone.zip` → run `Matilda.exe` (dropdown fixes; static hero)
- Rescan plugins after copying the VST3 folder.
