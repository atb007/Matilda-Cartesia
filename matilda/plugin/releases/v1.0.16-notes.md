## What's new in v1.0.16

### Windows — Rive hero (standalone + VST3)

- **Fix DXGI factory init:** v1.0.15 called `CreateDXGIFactory` with an `IDXGIFactory1` IID, which returns `E_NOINTERFACE` (`0x80004002`) and aborted D3D before any frame — static PNG only.
- Now uses `CreateDXGIFactory1`, with fallback to `CreateDXGIFactory` + QI, then a default hardware/WARP device if factory enum is unavailable.
- Expected log (`%TEMP%\MatildaRiveD3D.log`): `DXGI factory via CreateDXGIFactory1` → `loadBytes: ok` → `first D3D offscreen frame blitted to juce::Image`.

> macOS unchanged.

### Install

#### macOS
- **VST3:** unzip `Matilda-macOS-vst3.zip` → copy `Matilda.vst3` to `~/Library/Audio/Plug-Ins/VST3/`
- **Standalone:** unzip `Matilda-macOS-standalone.zip` → open `Matilda.app`

#### Windows (FL Studio, etc.)
- **VST3:** unzip `Matilda-Windows-vst3.zip` → copy `Matilda.vst3` to `C:\Program Files\Common Files\VST3\`
- **Standalone:** unzip `Matilda-Windows-standalone.zip` → run `Matilda.exe`
- Rescan plugins after copying the VST3 folder.

If Rive still fails, delete `%TEMP%\MatildaRiveD3D.log`, relaunch, and attach the new log.
